    This page shows the fingerprint of your client, measured by the server terminating this TLS
    connection. JA4 is the TLS ClientHello fingerprint, JA4H the HTTP request
    fingerprint, Akamai-H2 the HTTP/2 framing fingerprint. The verdict is a reverse lookup
    against the bundled dataset. Caveat: if this server sits behind a TLS-terminating proxy it measures the
    proxy, not you — front it with SNI passthrough (ssl_preread) instead.
