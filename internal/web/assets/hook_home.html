Request bins

Create a bin, then point any client at its capture URL. Every request is captured (method, URL, headers, body) with the caller's JA4 fingerprint when it arrives over TLS.

Bins and captured requests live in memory with a TTL and a global cap; they are not persisted. Captured content is attacker-controlled and is always escaped in the inspector UI.
